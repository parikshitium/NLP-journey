SEMANTIC SEARCH

A mini NLP project that retrieves semantically similar queries using Transformer embeddings and cosine similarity.

Dataset: banking77
Model: sentence-transformers/all-MiniLM-L6-v3
Libraries: Transformers, PyToech, Hugging Face Datassets
Evaluation: 92.07% Top-1 accuracy and 97.01% Top-5 accuracy
Learnings: Token embeddings, mean pooling, vector represantions,cosine similarity and semantic retrieval
