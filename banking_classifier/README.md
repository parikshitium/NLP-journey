BANKING INTENT CLASSIFIER

A mini NLP project that classifies banking-related queries into predefined customer intet categories

Dataset: banking77
Embedding Model: BAAI/bge-base-en-v1.5
Classifier: LinearSVC
Libraries: Sentence Transformers, Scikit-Learn, PyTorch, Hugging Face, Datasets
Learning: Sentence embeddings, supervised classification, LinearSVC, model evaluation
